# Chapter 10

# Editorial Review System

---

# Purpose

Writing creates content.

Editing creates authority.

The difference between average content and category-defining content is almost never the first draft.

It is the review process.

BRAINS does not publish first drafts.

Every article, blog, LinkedIn post, X thread, newsletter, landing page, whitepaper, documentation page, and AI-generated response must pass through the Editorial Review System.

The purpose is simple.

Every published sentence should improve founder thinking.

If it does not, it should not exist.

---

# The Editorial Philosophy

The first draft discovers ideas.

The review process sharpens them.

Editors do not rewrite.

Editors increase clarity.

Increase originality.

Increase usefulness.

Increase trust.

Increase memorability.

Every editing decision should make the reader smarter.

---

# The Five Editorial Passes

Every piece of content passes through five independent reviews.

## Pass One

### Strategic Review

Questions.

Is this worth publishing?

Is the insight original?

Does it reinforce the BRAINS positioning?

Does it solve a real founder problem?

Is there one core idea?

If the answer is no, stop editing.

Delete the draft.

---

## Pass Two

### Structural Review

Questions.

Is the hook strong?

Does curiosity continue naturally?

Does every section support the main idea?

Are transitions logical?

Does the conclusion reinforce the insight?

Can sections be removed?

Structure before wording.

---

## Pass Three

### Intellectual Review

Questions.

Are claims supported?

Is reasoning complete?

Have assumptions been challenged?

Would an experienced founder disagree?

Does the framework actually solve something?

Could this become a reusable mental model?

Ideas matter more than writing.

---

## Pass Four

### Language Review

Questions.

Can every sentence become shorter?

Can simpler words replace complex ones?

Can passive voice become active?

Can paragraphs become smaller?

Can repetition disappear?

Could someone read this twice as fast?

Writing should disappear.

Ideas should remain.

---

## Pass Five

### Editorial Polish

Questions.

Does the article feel like BRAINS?

Does it sound confident?

Does it invite thinking?

Would people save it?

Would people share it?

Would experienced founders respect it?

Only then is publication approved.

---

# The Delete Rule

The best editors delete aggressively.

Every paragraph must justify its existence.

If removing it changes nothing.

Delete it.

Every sentence should create value.

---

# The Clarity Test

Readers should never reread a sentence.

If they do.

Rewrite it.

Confusion destroys authority.

---

# The Compression Test

Take every paragraph.

Reduce it by twenty percent.

If quality improves.

Keep the shorter version.

Compression usually increases clarity.

---

# The Founder Test

Ask one question.

Would an experienced founder continue reading?

If not.

Find the weak section.

Rewrite it.

---

# The Bookmark Test

Would someone save this?

People save frameworks.

Not opinions.

People save explanations.

Not motivation.

Every article should contain at least one reusable asset.

---

# The Highlight Test

Could a reader highlight multiple sentences?

If nothing feels worth highlighting.

The article lacks insight.

---

# The One Sentence Test

Can the article be summarized in one sentence?

If not.

The article lacks focus.

---

# The Conversation Test

Would this naturally start a conversation among experienced founders?

Strong content creates thoughtful discussion.

Weak content creates agreement.

---

# Evergreen Review

Will this remain useful one year from now?

If yes.

Publish.

If not.

Improve the underlying thinking.

---

# Emotional Review

Readers should finish feeling.

Smarter.

More confident.

Curious.

Motivated to act.

Never manipulated.

Never overwhelmed.

Never sold to.

---

# Editorial Red Flags

Immediately reject content that contains.

Generic AI advice.

Listicles without insight.

Clickbait.

Motivational filler.

Unsupported claims.

Weak frameworks.

Artificial storytelling.

Trend chasing.

Long introductions.

Corporate language.

Repeated ideas.

Overexplaining.

Overusing adjectives.

Excessive jargon.

Em dashes.

These reduce trust.

---

# Publication Checklist

Before publishing.

✓ Original insight

✓ Strong opening

✓ Clear framework

✓ Evidence included

✓ Logical flow

✓ Practical value

✓ High readability

✓ Evergreen thinking

✓ Consistent BRAINS voice

✓ No em dashes

Only after every box is checked may the content be published.

---

# Closing Principle

Good writers create articles.

Great editors create institutions.

BRAINS wins through editorial discipline.

Not publishing volume.
