# BRAINS Content Skill

Version: 1.0

---

# Overview

The BRAINS Content Skill is the editorial intelligence system that powers all written content produced by BRAINS.

It is not a prompt library.

It is not a collection of templates.

It is an operating system for producing world-class startup content.

The objective is to create content that experienced founders, product managers, engineers, designers, investors, and startup operators genuinely want to read, save, reference, and discuss.

Every document inside this repository contributes to one goal.

Improve founder thinking.

---

# Mission

Create the highest-quality startup content on the internet.

Every article should educate.

Every framework should become reusable.

Every post should improve decisions.

Every interaction should strengthen the BRAINS knowledge ecosystem.

---

# Core Principles

Research before writing.

Evidence before confidence.

Frameworks before lists.

Reasoning before opinions.

Quality before quantity.

Knowledge before content.

Compounding before convenience.

# Contribution Guidelines

When adding new documents.

Maintain the BRAINS voice.

Follow the editorial constitution.

Avoid duplicate concepts.

Use existing terminology consistently.

Create reusable frameworks.

Support claims with reasoning.

Never introduce unnecessary complexity.

Never use em dashes.
